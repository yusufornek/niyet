# @niyet/core

> Shared business logic, domain types, ve cross-cutting utilities (web + mobile için).

**Faz 1'de doldurulacak**:
- `src/types.ts` — Zod schema'lar ve TypeScript tipleri
- `src/constants.ts` — 15 kategori enum, ikonlar, renkler
- `src/future-score.ts` — Future Score hesap fonksiyonu
- `src/savings-engine.ts` — Mikro tasarruf opportunity hesap
- `src/formatters.ts` — TL, tarih, percent formatları

Bu paket **UI agnostic** ve **infrastructure agnostic**. Sadece pure functions ve tip tanımları içerir.
